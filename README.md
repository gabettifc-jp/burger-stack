# burger-stack

バーガーを積んで売る、ブラウザで遊ぶ小さなゲーム。

## これは何か

7営業日、あなたはバーガー屋の店主です。

バーガーを1個ずつ積み上げて売り、営業日の終わりに家賃を払います。払えなければ閉店。
払えたら店が開くので、次の営業日に向けてデッキを組み直します。
7営業日を終えた時点の所持金で、店の格が決まります。

**あなたはバーガーの中身を直接は選べません。**選べるのはデッキ（山）の中身だけです。
何が積まれるかは山から引かれて決まるので、
「引きたいものが引かれる山」を作ることが、そのまま戦略になります。

具材とソースには **和・中華・揚げ物・高級・海鮮** の5つの軸があり、
軸を揃えると噛み合う効果を持つカードがあります。
軸に寄せて一点を狙うか、強い札を広く集めるか。デッキの組み方はそこで分かれます。

## 遊び方

1. **積む。**ボタンを押すとバーガーが1段ずつ積まれ、完成すると売値が付いて所持金に入ります。
2. **カードを1枚もらう。**完成のたびに3択が出ます。選んだ1枚がデッキに入ります。見送ってもかまいません。
3. **家賃を払う。**営業日の終わりに家賃が来ます。既定では**所持金に比例する額**なので、
   稼ぐほど家賃も上がります。払えなければ閉店です。
4. **店で買う。**家賃のあとに店が開きます。買えるのは次の6つです。
   - カードの追加
   - デッキからカードを削除する
   - 具材枠（1回のバーガーに積む具材の数）
   - ソース枠（同じく、ソースの数）— 上限3枚。2枚目 ¥2,000・3枚目 ¥12,000
   - 引き直し（店の品揃えを引き直す）
   - アーティファクト（ラン全体に効く道具）
5. **これを7営業日くり返す。**最終日を終えると評価が出ます。

始まりのデッキは **パティ・チーズ・きゅうり・ケチャップ** の4枚だけです。ここから育てます。

### 動作環境

ブラウザでファイルを開くだけで動きます。**スマートフォンのブラウザでも遊べます。**
`index.html` 単体・ビルド不要・依存ライブラリなし・インストール不要。

現在の中身は具材72枚・ソース34枚・バンズ1枚の**カード107枚**と、**アーティファクト39個**です。

## 開発者向け

### 実装方針

HTML / CSS / JavaScript のみ。ビルド不要・依存ライブラリなし。
ブラウザでファイルを開けば動くこと。数値はすべて調整欄から変えられる状態を保つこと。

### 開発用の機能

調整パネル・プレイログ・⚙️調整ボタンは、**URL に `?dev=1` を付けたときだけ**出ます。

```
index.html          遊ぶ人が見る画面
index.html?dev=1    開発用の機能つき
```

`?dev=1` が無いときは、この3つは CSS で隠されるのではなく **DOM から取り除かれます**。
あわせて次の2つも `?dev=1` のときだけ動きます。

- **調整欄の保存設定の読み書き**（`localStorage` の `bstack.cfg.v1`）
- **プレイログの記録**（`bstack.plog.*`）

保存済みのデータは消えません。`?dev=1` で開けば今までどおり読めます。

### 測定

`tools/m4-measure.mjs` が Playwright で実際の UI を操作してランを回し、
1ランにつき JSON 1行を書き出します。内部関数を直接呼ぶ経路は使いません。

```
node tools/m4-measure.mjs --policy=base --from=3001 --to=3036 --days=7 --out=out.jsonl
```
