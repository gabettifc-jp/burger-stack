# burger-stack

バーガーを積み上げて得点を出す、実験段階の小さなブラウザゲーム。

## これは何か

確かめたいことは一つだけ ——「バーガーを積むこと自体が面白いか」。

デッキ（山）の中身を変えて連打し、「さっきより明らかに当たりが増えた」と
体感できるかを見るための最小構成の試作。詳しい仕様は [SHIYOU.md](./SHIYOU.md) を参照。

面白さの指標は平均点ではなく **最高点 ÷ 平均点**。これが3倍以上出れば、
点数の落差（=面白さの本体）が成立していると判断する。

## 遊び方

1. ボタンを押すとバーガーが1個できて点数が出る。
2. プレイヤーはバーガーの中身を選べない。操作できるのは山（デッキ）の中身だけ。
3. 画面下の3つの山を＋−で調整 → 連打 → 点数の落差を棒グラフで見る、を繰り返す。
4. 数値の調整欄（折りたたみ）で、基礎点・倍率・加算・食い込み量・演出速度を
   その場で変更できる（保存はしない。リロードで初期化）。
